  ABERTURA — O PORQUÊ  [~40 segundos]

"Qual regra tá sendo aplicada aqui?"

================================================================
  PROBLEMA  [~30 segundos]
================================================================

O caminho óbvio seria: conecta uma IA nos dados,
a pessoa pergunta em português, recebe a resposta.

[PAUSA]

Mas o problema é que a maioria das implementações
manda a pergunta direto pro modelo e torce pro SQL sair certo.

[PAUSA]

Uma pergunta como "o que você faz?" vira um SELECT.
O modelo alucina uma coluna que não existe.
A confiança vai embora.

[PAUSA — fala mais devagar]

A Astra foi construída para não fazer isso.

[PAUSA LONGA]

================================================================
  SOLUÇÃO  [~60 segundos]
================================================================

A Astra resolve isso de forma simples:

você pergunta em português...

[PAUSA]

...ela responde com dados.

[PAUSA]

Sem SQL. Sem planilhas. Sem depender de ninguém.

[PAUSA CURTA]

---

A Astra é uma analista de dados com IA,
construída com três tecnologias:

  · Streamlit — uma interface web limpa e intuitiva

  · DuckDB — um banco de dados analítico ultra-rápido,
              rodando 100% local, sem nuvem

  · Claude Haiku da Anthropic — o modelo de IA que entende
    sua pergunta e gera a análise

[PAUSA CURTA]

O fluxo é direto:

você digita uma pergunta
→ a IA converte para SQL
→ executa no banco
→ te entrega resposta, gráfico e os dados brutos.

Tudo em segundos.

[PAUSA]

================================================================
  DEMONSTRAÇÃO  [~60 segundos]
================================================================

[SE TIVER COMPUTADOR: abra o app e mostre ao vivo]
[SE TIVER VÍDEO: "Deixa eu mostrar como ela funciona na prática."]

---

Vou perguntar para ela: "Quais são os 10 produtos mais vendidos em 2024?"

[PAUSA — aguarda o resultado aparecer]

Olha o que acontece —
resposta em texto, gráfico já formatado,
o SQL que foi executado, e os dados brutos.

[PAUSA CURTA]

Agora: "Qual o faturamento mensal de 2025?"

[PAUSA]

Linha do tempo, tendência — tudo organizado.

[PAUSA CURTA]

"Como as vendas se distribuem por estado?"

[PAUSA — deixa o gráfico falar]

Simples assim.

[PAUSA]

================================================================
  TECNOLOGIA & DIFERENCIAIS  [~30 segundos]
================================================================

O que diferencia a Astra não é só a IA. É a arquitetura:

  · O banco roda local — os dados da empresa nunca saem
    do ambiente dela

  · A IA classifica cada pergunta antes de gerar SQL —
    evita erros e respostas sem sentido

  · A interface guia o usuário com sugestões,
    sem exigir nenhum conhecimento técnico

[PAUSA]

================================================================
  IMPACTO  [~20 segundos]
================================================================

O mercado de analytics está em expansão acelerada.

Mas a maior parte das ferramentas é cara, complexa,
e pensada para times de dados.

A Astra é para quem toma decisão —
o gerente, o dono, o analista de negócio
que não quer depender de intermediários.

[PAUSA]
